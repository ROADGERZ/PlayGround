## Crypto AI Pro

An AI-native crypto intelligence and trading terminal that runs entirely in the
browser. It is a self-contained static app: no build step, no backend, no API
keys required.

**Highlights**

- **Overview desk** — live portfolio KPIs, an interactive performance chart with
  an AI forecast band, a top-signal card and a market-intelligence feed.
- **Markets** — 10 assets with live prices, 7-day sparklines, category filters,
  search, sorting and Oracle AI scores.
- **AI Signals** — six high-conviction setups ranked by model confidence, with
  entry/target/stop levels and one-click execution.
- **Portfolio** — holdings table, allocation donut, risk profile and activity log.
- **Backtest Lab** — configure a strategy and simulate it, producing an equity
  curve, risk metrics and a trade log.
- **AI Copilot** — a contextual chat assistant that answers questions about any
  asset, the portfolio and current signals (`/` to search, `⌘K`/`Ctrl+K` to open).
- **Execution modal** — buy or sell with live pricing, fee preview and an AI risk
  check; trades update the portfolio and persist to `localStorage`.

**Data**

Prices are fetched live from the public CoinGecko API when the network is
available and fall back to a deterministic simulated feed otherwise. The
portfolio is a demo book for illustration only — nothing here is financial advice.

**Run it locally**

```sh
python3 -m http.server 3000
# then open http://localhost:3000
```
